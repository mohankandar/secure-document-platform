# SecureDoc Platform V1 — Requirements Summary

## Product Purpose

Secure document intelligence, redaction, human review, vault, and audit platform.

## Core Capabilities

1. Document intake (upload, shared-folder, API)
2. Document processing (OCR, text extraction, sensitive-data detection)
3. Policy-driven redaction
4. Human review workflows
5. Secure vault registration
6. Controlled access/download
7. Audit timeline
8. Tenant-aware configuration

## V1 Scope

Local/demo first. Single tenant. REST API. PostgreSQL persistence.

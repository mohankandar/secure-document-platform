# Unit Execution Rules

- Work one unit at a time
- Complete the current unit fully before moving to the next
- Each unit must leave the build in a clean, compilable state
- Do not add tests until the project shape stabilizes (team decision)
- Do not implement features from future units
- Report clearly at the end of each unit what was done and what's next
- If a unit's scope grows too large, propose splitting it — don't just keep going

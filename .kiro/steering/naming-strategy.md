# Naming Strategy

- Internal codename: LexaVault (docs/planning only)
- Market name: TBD (decided later)
- Java namespace: com.securedoc.platform.*
- Maven prefix: securedoc-*
- Domain class names: descriptive/functional (DocumentPackage, ReviewTask, VaultEntry, PolicyRule, AccessRequest, AuditRecord)
- Never use LexaVault in code packages or class names
- Never create classes like LexaVaultPackage, LexaVaultDocument, LexaVaultPolicy

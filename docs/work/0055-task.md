Check LexaVault for the same kinds of issues Vero's review found, fix what applies (each fix small and contained; anything bigger becomes a finding in `docs/work/security-findings.md`):

3. **Dev services listening on all addresses:** local start scripts and default settings bind the app, scanner bridge, frontend and test containers to `127.0.0.1` unless a setting says otherwise; production binding is an explicit setting.
4. **Security findings are not published before they are fixed** (owner decision, SDV-18): keep `docs/work/security-findings.md` free of how-to detail for open items; commit and PR messages describe fixes plainly.

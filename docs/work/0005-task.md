# Task 0005: fix R-08 in the Enterprise Identity library, then rerun the Phase 1 checks

Written: 2026-11-17, by the design chat.
Owner approval: by starting this task, the owner approves a change in a frozen area (the Enterprise Identity library), limited to what is described here. The reason is a demonstrated defect found in Phase 1 (report 0004, R-08).

## The defect

`RequiredAudienceValidator.validate` calls `token.getAudience().contains(audience)`. When a token has no `aud` claim, `getAudience()` returns null, the call throws, and the backend answers 500 with a stack trace instead of 401. The request is still refused, but any caller can trigger an error and a stack trace in the log. SDV uses the same class, so it has the same defect.

## Part A: the library (`C:\dev\shared\enterprise-identity-parent`)

1. Create a branch `fix/null-audience-validator` from `main`.
2. Make `RequiredAudienceValidator` treat a missing or empty audience as "required audience is missing": return the existing failure result, never throw. Change nothing else in the class.
3. Add unit tests for the validator. The module has none today. Cover at least:
   - no `aud` claim: failure result, no exception;
   - empty `aud`: failure;
   - `aud` present but not ours: failure;
   - `aud` equal to ours: success;
   - `aud` with several values including ours: success.
   If the module has no test dependencies yet, add only what these tests need, and list what you added in the report.
4. Set the library version to `0.2.1` in every place it is declared.
5. Run `mvn clean install` in the library. Report the test count.
6. Commit on the branch. Do not push.

Do not make any other change in the library. No refactoring, no new features.

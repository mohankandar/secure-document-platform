Answers to 0066's questions 1–2:
- **(1)** Review and Approval get **"Reject case"** for the people who may review or approve today. The case ends as **Rejected**; nothing is exported; files follow normal retention; it can't be undone (the source sends a new case). A confirmation dialog names the case and the reason. No new notification in V1 beyond what a finished case already triggers for its source.
- **(2)** Reason codes (new `LV-` codes in the catalogue and its document): wrong document, unreadable, out of scope, duplicate, other (see ticket). Never free text. The code goes to the **audit trail, the Cases list (plain name) and the API status answer**.

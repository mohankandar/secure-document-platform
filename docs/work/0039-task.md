## 1. Page number for text-reading failures
When text reading (OCR) fails on a page (timeout or error) in `TesseractOcrAdapter` / `HybridPdfTextExtractionAdapter`, the failure carries the **page number (an integer, 1-based) and nothing else** up to the incident metadata (`page`), so Support shows "document 2 of 3, page 14" (0038 already displays it when present).
- Only the number: no text, no image, no file name, no excerpt of the error output.
- V1 behaviour otherwise unchanged: same retries, same outcome, same codes.
- Tests: a failing page reports its number; a non-page failure reports none; the no-redacted-value check stays at 0 matches.

## 2. Integration source limits capped at the case limits
Integration sources (push, scanner, polling, watched folder) can be set today to up to 2,000 pages per file and 1,000 documents. Cap them at the case limits from `CaseLimits`: **500 pages per file, 50 files per case**.

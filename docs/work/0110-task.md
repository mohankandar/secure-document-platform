# 0110: Hardening, part 2

Queue A, owner-approved 2026-11-27. The plain rules only (the queue holds the full task).

1. Outbound addresses limited for sources and destinations: loopback, link-local, private ranges and plain http are refused unless the IT Administrator allow-lists the host by name for that connection. Checked on save and at connect time (after name resolution). An LV error names the field.
2. Endpoints deny by default: a controller method without a capability rule is refused. One test walks every endpoint and fails if any lacks a rule (explicit public ones listed).
3. Audit table protected by the database: the app's database user may insert and read audit rows, never change or delete them. A test shows an update is refused.
4. Text model pinned and local: digest pinned in configuration, AI server on a local or allow-listed address; start refuses with a clear message when the digest differs. The local start script keeps working.
5. Polling answer size limit (default 20 MB, admin setting); a larger answer is refused with an LV code and nothing is stored.

Done when: merged on green CI, TO-TEST.md entry, report lists anything the owner must do.

# Historical Documentation Archive

Files in this directory are intentionally retained as implementation/decision history.

They include:

- unit implementation and approval records;
- Kiro verification plans/prompts;
- pre-acceptance self-reviews;
- superseded role/authorization models;
- one-time runtime defect reports;
- historical requirement freezes;
- obsolete local-run instructions.

## Important

Archived files are **not current specifications**. They may contain retired roles, old implementation status, superseded command sequences, or statements that were correct only at that point in development.

For current work, start at `../README.md` and `../continuity/CURRENT_STATE.md`.

## Final runtime correction

The acceptance run found one genuine blocking persistence defect: `DocumentMapper.toDomain` reconstituted a reloaded `Document` with an empty page list, making `document.pageCount()` zero even though `page_count` had been persisted. This broke independent redaction verification after reload.

The minimal fix rehydrates placeholder `Page` entries from the persisted `page_count`. Full text/geometry is still not persisted and continues to be re-derived from the original artifact when required. The full backend build and acceptance matrix passed after this correction.
